# Ziada POS language support

The application supports English (`en`) and Swahili (`sw`). The language switcher is available in the dashboard header immediately before the theme control.

## Rules for future work

- Never add user-facing copy directly to a new feature without adding both English and Swahili translations.
- Use `useLanguage()` in client components and `t('key')` for shared UI copy.
- Keep translation keys semantic and stable; do not use English sentences as keys.
- Format currency and dates with the active locale where the user is seeing localized content.
- Keep product names, customer names, SKUs, receipt numbers, and other business data unchanged.
- For server-rendered pages, pass translated copy from a locale-aware server boundary when the feature needs translated metadata or initial HTML.
- If a new phrase is needed, add it to both dictionaries in `src/lib/i18n.tsx` before using it.

The selected language is persisted in `localStorage` as `ziada-language`. Swahili is the default for new browsers because most Ziada POS users are expected to be Swahili speakers.
